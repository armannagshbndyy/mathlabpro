اعداد اول: isPrime() → بررسی اول بودن عدد, checkPrime() → نمایش اول یا مرکب, listPrime() → لیست اعداد اول تا n, factorPrime() → نمایش فاکتورهای عدد;

ماشین حساب: calcAdvanced() → محاسبه عبارات ریاضی (جمع، تفریق، ضرب، تقسیم، توان، پرانتز); لطفا برای جواب درست رادیکال و ... را وقتی به رویش ضربه زدید عدد را داخل پرانتز بزارید و پرانتز ببندید.

تحلیل لیست: analyzeList() → بیشترین، کمترین، مجموع و میانگین لیست اعداد;

توابع و رادیکال: sqrt(x) → ریشه دوم،
cbrt(x) → ریشه سوم،
pow(x,y) → توان،
abs(x) → قدر مطلق،
sin(x) → سینوس (درجه)،
cos(x) → کسینوس (درجه)،
tan(x) → تانژانت (درجه)،
log(x) → لگاریتم طبیعی،
log10(x) → لگاریتم پایه 10،
factorial(x) → فاکتوریل،
gcd(a,b) → ب.م.م،
lcm(a,b) → ک.م.م،
mean(...) → میانگین،
variance(...) → واریانس نمونه
solve(عبارت جبری)
مثال:
solve(2x + 3x)
solve(x^2 + 5x + 6)
solve(3x + 9)

🤖 محاسبات هوشمند: در این بخش می‌توانید مسئله‌ی ریاضی خود را به صورت **متنی و آزاد** وارد کنید و سیستم به صورت هوشمند حل می‌کند.

نمونه ورودی‌ها:
  • حل معادله: حل کن: 3x + 7 = 16
  • مشتق: مشتق x^3 یا مشتق sin(x^2)
  • انتگرال: انتگرال x^2
  • محاسبات عددی: (5+3)*2 یا sqrt(16) + 4^2
  • لیست اعداد: 1,2,3,4,5 (محاسبه میانگین و مجموع)
نکات مهم:
  • متغیر پیش‌فرض معادلات x است
  • برای توان از ^ استفاده کنید
  • توابع مثل sin، cos، sqrt باید به انگلیسی نوشته شوند
  • برای عبارات پیچیده از پرانتز استفاده کنید
توجه: اگر مسئله شما پیچیده بود، آن را ساده‌تر یا مرحله به مرحله وارد کنید.

هندسه: squareArea(a) → مساحت مربع, rectArea(a,b) → مساحت مستطیل, circleArea(r) → مساحت دایره, squareVol(a) → حجم مکعب, cylinderVol(r,h) → حجم استوانه, sphereVol(r) → حجم کره;

نمودار: drawChart() → رسم نمودار ساده از لیست اعداد;
